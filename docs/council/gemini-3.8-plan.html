Council draft · Gemini 3.8 Flash · not the agreed plan

A matrix HUD, and a personal space under every row

Todo apps are shame engines. Manager borrows the gacha loop: bounded slices, a reset that does not create debt, and an agent as the external prefrontal cortex.

Introduction

A conventional list turns yesterday into a wall of red badges. The ADHD failure mode is abandonment, not laziness. Live-service games already know the fix: dailies, weeklies, seasons, and tracks that pay off inside a bounded slice. Missing a day must not become an unpayable debt.

The early absolute rule “dailies never stack” is wrong. Dishes refresh in place, because you cannot wash yesterday’s dishes. A journal or a medication log must keep the missed day. Each series stores replace or stack.

The loop is agent, then Manager, then native push, calendar, reminders, and alarms. People should not triage mail into a spreadsheet. They open a HUD, clear a slice, and get the ping. The manual UI is the steering wheel.

Positions this draft will not soften

  • Every task, category, event, progression, and quest belongs to exactly one space. A personal space is created on first sign-in. Sharing means another space, not a side ACL.
  • dueAt is the hard deadline. plannedDate is the civil day. plannedTime is optional minutes from midnight.
  • Two span kinds: timeWindows (Today, this week, Q4) and events (Winter, a tax sprint, a trip). A season is an event with a longer window and a presentation id. Length is not checked.
  • Retire removes the row from active views by setting deletedAt, or an expired archive. No red badge.
  • Priority is a closed number: 0 critical, 1 high, 2 normal, 3 low. Packs may paint those as SSR, SR, R, and common. The number stays in the core.
  • Overdue has three policies: retire, escalate, and carry_forward.

Domain

Soft delete is universal: mutations patch deletedAt, live queries filter it, restore clears it. No ctx.db.delete(). Multi-attach is a taskAttachments junction (category, event, timeWindow) plus denormalized primaryCategoryId and primaryEventId on the task for fast slices. The core accepts more than one attachment. Replace keeps a single pending task and moves its window forward. Stack leaves each missed day alive. Quest steps point at real tasks. The backend unlocks the next discovered step. It does not interpret a landlord’s sentence. The agent appends the continuation over MCP. A known relocation checklist is the same tables, prefilled.

Rollover is lazy on read for the active space, plus a reconciliation cron about every six hours so a push can fire even if the app stays closed.

Behaviors

Replace: dishes, trash, a daily tidy. Stack: journal, medication, study log, receipts. Priorities P0–P3. Starter quests: Repair the Broken Window (step 2 hidden), Apartment Relocation Protocol (four known steps). Starter tracks: Dune, 688 pages; 100 days of movement.

Vertical rail: categories, then Quests, then Seasons. Horizontal bar: Today, This week, Limited, Tracks. The cell is the slice. Cards and rows toggle per slice. Bars are cards or a pin along the top.

Command deck. A time scrubber on top, categories in a drawer, timed tasks beside untimed ones. Campaign map. Quests down the side, places across the top, tasks as nodes. Daily commissions sit in a corner.

A pack is a client bundle: tokens, icons, optional chimes and particles. Convex stores only presentationId (gacha-cyberpunk, nordic-minimal). Unknown ids use default-clean. Open debate: which pack is the default for a new account.

User flows

  1. Dishes, replace. Tuesday night you skip them. Wednesday’s rollover moves that one task onto Wednesday. One row. No overdue badge. You do not mark Tuesday done.
  2. Journal, stack. Two missed days stay. Thursday shows Tuesday, Wednesday, and today. You can backfill.
  3. Taxes, escalate. The agent sets dueAt to 15 Apr 23:59, priority 1. On 16 Apr the sweeper sets priority 0, pins the HUD, and the agent offers to help.
  4. Holiday pie, retire. A 7-day limited event. On 25 Dec the task’s deletedAt is set. Christmas morning it is gone. No red mark.
  5. Broken window. Emergent quest, only “call the landlord” is discovered. You complete it and note what they said. The agent appends “get two quotes” and “deduct the invoice from rent”. A chime plays. Step 2 lights up.
  6. Dune. Target 688 pages. A daily “read 20 pages” logs +30. The bar hits 25% and a waypoint fires.
  7. Apartment 4B. Invite a partner as member. Attach Household, the window quest, and the grocery series. Their Android check-off lands on your Mac. Personal spaces stay private.
  8. Tokyo mail. One agent pass calls create_event, create_quest, add_quest_step, and create_task for the flight. The event banner and the quest are already there when you open the app.

Technical plan

Schema grows in packages/backend/convex/schema.ts. New task fields are optional so current tasks:list subscribers keep working. Indexes proposed: by_owner_deleted, by_space_deleted, by_space_category, by_series. Queries use deletedAt === undefined on those indexes.

Migration: add optional fields; auto-provision a Personal space on requireUser; backfill spaceId; then change deleteTask from db.delete to a tombstone.

MCP stays thin over the existing HMAC proof. Tools: the current task set plus update_task and soft_delete_task; spaces; categories; events; create_recurrence_series; progressions; create_quest, add_quest_step, advance_quest; and batch_sync_plan so an email can become an event, a quest, and tasks in one transaction. Clients do not compute rollover, percent, or access. Apple decodes floats with @OptionalConvexFloat. Android uses Float64.

Milestone 3’s matrix ships on web and desktop first in this draft, with native filtering called out in the same milestone rather than as a separate product.

Debates this draft leaves open

  • Junction table plus denormalized primary ids: worth the sync risk, or too clever for a life-sized list?
  • Lazy rollover versus a cron that must run so notifications fire for a closed app.
  • Is creating a space too heavy for sharing one grocery list?
  • Default skin: gacha cyberpunk or nordic minimal?
  • Should a multiple-choice quest branch work with no agent connected?
